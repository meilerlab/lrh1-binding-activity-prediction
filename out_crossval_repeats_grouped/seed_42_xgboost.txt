Training and crossvalidation code. Reads CSV files from ../data/ folder.
  - random_state seed is set to 42, jumbled flag set to False
  - binder_label is True if abs(Cyp7 Avg, L2FC) > 0 ; used as proxy, any measured property except for PGC works.
  - coreg_label is True if abs(PGC Avg, L2FC) > 0.45
  - activity_label is True if ANY abs(PGC Avg, Cyp7 Av, Cyp8 Avg) is > 0.45
